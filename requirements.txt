5. **Create the First Python Script**:
   For **task automation**, start with something simple, like renaming files.

Example (`task_automation/rename_files.py`):
```python
import os

def rename_files_in_directory(directory_path):
    for filename in os.listdir(directory_path):
        old_file = os.path.join(directory_path, filename)
        
        if os.path.isfile(old_file):
            new_file = os.path.join(directory_path, filename.lower())  # Convert to lowercase
            os.rename(old_file, new_file)
            print(f'Renamed: {filename} to {filename.lower()}')

if __name__ == '__main__':
    rename_files_in_directory('/path/to/your/files')  # Adjust path
